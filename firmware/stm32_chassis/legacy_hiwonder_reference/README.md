# Legacy Hiwonder Factory Reference

This directory contains the original Hiwonder factory CubeMX project file for reference only.

**DO NOT USE FOR ACTIVE DEVELOPMENT**

- `RosRobotControllerM4.ioc` - Original Hiwonder factory CubeMX project (ProjectName=RosRobotControllerM4)
- This is the fallback factory software for the STM32F407 chassis controller
- Active development uses `../RosRobotControllerM4.ioc` in the parent directory.

If you need to regenerate HAL code from CubeMX, use the active
`../RosRobotControllerM4.ioc` and keep generated changes under review.
